# Digital Financial Access and Economic Resilience — Replication Package

Replication code, archived raw input data, and generated output for **"[A Sign, Not a Magnitude: Digital Financial Access and Economic Resilience in the COVID-19 Crisis](https://www.dropbox.com/scl/fi/yqikkgj5ddi72zqkf2qtx/digital_finance_resilience.pdf?rlkey=a7s67336w6eh80fx214br4wnq&st=bvxfwvnx&dl=0)"** by Xinchen "Sisi" Qiu.

The scripts run entirely from local files in this repository; they do **not** download data from any API.

## Requirements

- Tested with Stata 19.5.
- The following user-written packages, installable from SSC:

  ```stata
  ssc install estout // eststo, esttab, estadd, estpost
  ssc install ivreg2
  ssc install ranktest // required by ivreg2
  ssc install weakiv
  ssc install binscatter
  ```

Please install these once before running the scripts. The scripts do not install anything automatically, so they will not modify your Stata setup. Figures use Stata's default graph scheme.

## How to run

To reproduce the full analysis, run **only the master script** `0_run_all.do`. It can be launched from either the project root or the `code/` folder.

From the project root:

```stata
do "code/0_run_all.do"
```

Or, from the `code/` folder:

```stata
do "0_run_all.do"
```

The master script configures project paths automatically and runs the four analysis scripts in sequence, regenerating the cleaned dataset, all tables, and all figures. No other script needs to be run separately for full replication.

To run an individual analysis script on its own, run `_config.do` first.

A few benign, non-fatal messages may appear in the log (for example from `ivreg2, first`); they do not affect the produced tables or figures.

## Raw data

Raw Findex and WDI extracts are included **as-is** in `data/raw/`:

- `data/raw/DatabankWide.dta` — Global Findex extract (downloaded in DTA format from the [Global Findex Database](https://www.worldbank.org/en/publication/globalfindex/download-data) in January 2025).
- `data/raw/world_development.csv` — World Development Indicators (WDI) extract (downloaded in CSV format from the [World Bank DataBank](https://databank.worldbank.org/source/world-development-indicators) in February 2025).

The archived extracts reflect the country, year, and indicator coverages downloaded for the analysis at the time. Additional sample restrictions are applied in the scripts. Because both WDI and Findex series are revised over time, re-downloading the data today may **not** reproduce these files. The archived extracts included here are therefore the canonical inputs for replication.

The World Development Indicators (WDI) and country-level Global Findex data used in this replication package are distributed by the World Bank; see `license/` for the applicable licensing information. The raw WDI file included in this repository is the original download from the World Bank DataBank used for the analysis. Indicator-specific licensing and usage terms are described in the accompanying World Bank metadata.

## Repository layout

| Path | Contents |
|------|----------|
| `_config.do` | Configures project paths, Stata session settings, and output folders. |
| `code/0_run_all.do` | Master script; runs the four analysis scripts in order. |
| `code/1_clean_main_data.do` | Cleans and merges the raw Findex and WDI files, constructs the economic-resilience and digital-financial-penetration indices, and saves the analysis dataset. |
| `code/2_desc_stats.do` | Descriptive statistics, index-validation regressions, and exploratory figures. |
| `code/3_main_IV.do` | Main baseline and crisis-specific instrumental-variable specifications. |
| `code/4_robust.do` | OLS specifications and candidate-IV diagnostics. |
| `data/raw/` | Archived raw inputs (see above). |
| `data/proc/` | Intermediate and final processed datasets (regenerated by the scripts). |
| `dictionary/` | Variable dictionaries for the raw inputs. |
| `graph/` | Output figures (PDF). |
| `license/` | Licenses for the raw inputs. |
| `table/` | Output tables (LaTeX). |

## Final dataset

`data/proc/combined_clean.dta` is the final analysis dataset: country-year identifiers, income-group and pandemic-period variables, the constructed standardized indices and component factors, the controls and instruments used in the tables, and the raw component variables needed for descriptive output.
